#  Автоматическая отправка писем с вложением (Python + Gmail)

Проект на Python, который автоматически отправляет электронные письма с вложенным файлом (CSV) через Gmail. Скрипт работает в бесконечном цикле и отправляет письма каждый час.

---

##  Структура проекта
Proect3_Python/
- hourly_email_sender.py   # Основной скрипт (отправка по расписанию)
- test_send.py             # Тестовый скрипт (быстрая проверка связи)
- run_hourly_email.bat     # Файл для удобного запуска в Windows
- README.md                # Этот файл
